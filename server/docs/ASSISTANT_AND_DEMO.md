# Assistant and Synthetic Demo Notes

The optional Bizi assistant is served under `/api/assistant`. It can answer from curated methodology help and authorized campaign/profile context; creator profile and self-reported metric updates use preview-and-confirm proposals. Businesses create campaigns and request trained ML recommendations through the campaign workspace, not through an assistant-generated recommendation run. Assistant availability depends on optional server-side provider configuration; the core marketplace and recommendation workflow do not require it.

The complete synthetic demo seed is an optional development fixture. It creates a tagged business, 300 synthetic Bizi creator accounts/profiles, and synthetic campaigns. Its identities, metrics, quotations, and latent vectors are not real creator evidence. Run `node scripts/migrateRecommendationV1.js` before the seed when the demo evidence tables are needed, then `node scripts/seedCompleteDemo.js` from `server/`. The script writes local-only credentials and a generated manifest under `server/data/complete-demo` by default; do not commit those outputs.

The primary production recommendation flow remains `POST /api/campaigns/:campaignId/ml-recommendations`, backed by FastAPI and the trained Random Forest artifact described in the root README. Legacy V1 ranking routes are retired; historical tables are preserved and are not the business dashboard recommendation authority.
